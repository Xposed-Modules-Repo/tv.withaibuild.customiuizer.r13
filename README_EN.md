# 米客 A13｜CustoMIUIzer A13

[简体中文](README.md) | English

CustoMIUIzer A13 is an Xposed module for customizing the system UI, launcher, and interactions on **MIUI 14 / Android 13**. **HyperOS 1 / Android 13** support is experimental.

[Download the latest stable release](https://github.com/Xposed-Modules-Repo/tv.withaibuild.customiuizer.r13/releases/latest) · [Release history](https://github.com/Xposed-Modules-Repo/tv.withaibuild.customiuizer.r13/releases) · [Changelog](CHANGELOG_EN.md)

See the [source repository README](https://github.com/thetvplus/customiuizer-a13/blob/main/README_EN.md) for installation, framework, and device requirements. Before upgrading from a version signed with the previous certificate, read [signing and upgrades](https://github.com/thetvplus/customiuizer-a13/blob/main/COMPATIBILITY.md#签名与升级).
